一个进程没有映射某块内存，它就读不到那里。这个结论放到进程身上很直接，但如果旁边还有一个正在搬数据的设备呢？

设备发起的 DMA 不必经过这个进程的页表。讨论整颗 SoC 的隔离时，最容易漏掉的，就是把 CPU 这一条访问路径当成所有访问路径。

先用一块普通缓冲区把问题读清楚。下面的地址是教学示意，不属于任何手机；具体安全资源的范围仍由平台配置决定。

## 同一块内存，可以有三种地址

假设驱动分配一块缓冲区，CPU 通过内核虚拟地址读写它，设备则通过驱动交给它的 DMA 地址访问。背后可以是同一片物理内存，但三个地址不必具有同样的数值。

```text
CPU 虚拟地址 ──CPU 地址转换──┐
                            ├── 同一块物理内存
设备 DMA 地址 ─设备侧映射───┘
```

图中第二条映射可能涉及 IOMMU，也可能在某个平台上采用直接映射或其他处理。Linux 的 [DMA mapping guide](https://docs.kernel.org/core-api/dma-api-howto.html)特意区分了 CPU 虚拟地址、物理地址和设备使用的总线地址，并解释 DMA API 为什么返回单独的地址。

这对读驱动很重要。看到一个 `dma_addr_t`，不该把它强制转换成 CPU 指针再解引用；看到两个地址不同，也不该立刻判断数据被复制了。它们可能只是同一个对象在两条访问路径上的表示。

再往下一层，MMU 或 IOMMU 的映射还受到上下文约束。同一数字，在不同进程或设备域里，可以指向不同资源。没有上下文的地址，只是一串不完整的线索。

## SRAM 和 DRAM 并没有替你选好权限

SRAM、DRAM 先描述存储电路及其使用条件。DRAM 需要刷新和相应控制器初始化，早期启动与初始化完成后可用的内存也会不同。但这些区别不等于安全权限的划分。

把一段数据搬到外部 DRAM，并不自动把它交给普通世界；把数据留在片上 SRAM，也不自动保证只有安全侧能读。权限取决于实际访问路径与保护规则。

因此，读固件时遇到 `secure_buffer` 这样的符号，可以把它作为搜索入口，但要继续追踪谁配置了这段资源、哪些访问主体受到约束。名字帮助理解代码意图，硬件规则决定访问结果。

## 页表少了一项，只堵住了一条路

假设某区域没有映射到普通进程，甚至普通侧 CPU 的相关映射也被限制。如果设备仍可对目标地址发起访问，那么 CPU 侧的限制不足以描述整颗芯片的边界。

SMMU/IOMMU 可以把设备请求放到相应的转换与权限环境里，平台还可以在互连或内存控制侧配置资源保护。但“芯片有 SMMU”只是能力描述；某个设备是否经过它、使用哪个域、是否绕过转换，需要具体配置。

换成一个小问题就清楚了：驱动把缓冲区交给网卡时，网卡得到的地址属于哪个设备映射？这份映射允许多大范围，什么时候失效？先把这条路径画出来，比给整块 DRAM 涂上 Secure 或 Normal 颜色更有用。

关于地址转换本身，可继续读 [Arm A-profile 的架构专题](https://www.arm.com/architecture/learn-the-architecture/a-profile)。这里不替某款 SoC 指定保护寄存器或接线方式。

## 读到了旧值，不一定是权限的问题

接下来容易混淆的是缓存。设备确实写了缓冲区，CPU 却还看到旧内容；这时应先看缓存一致性、映射方式和同步，而不是直接归因于设备越权。

对于 streaming DMA，CPU 与设备之间的所有权切换需要遵守相应 API 的同步规则。即使使用 coherent DMA，访问顺序也仍然重要：如果 CPU 先让设备看到“描述符有效”，后让它看到描述符里的地址，设备可能提前按不完整的数据工作。Linux 文档明确指出，一致性内存并不会消除内存屏障的需要。

这两类问题的差别是：缓存与顺序决定双方何时看到什么；隔离决定谁有资格访问什么。修好前者，没有证明后者正确。

## 释放动作为什么也是边界

假设设备还在写，驱动已经回收缓冲区，同一片物理内存随后分给别的对象。旧设备请求即使原本完全合法，现在也可能落到新对象上。

所以 DMA 缓冲区的分析不该停在“分配成功、地址有效”。需要把设备完成通知、停止或同步、解除映射、最后释放串起来。到底采用哪些步骤取决于驱动与 DMA 模式，重点是最后一次设备使用必须和回收建立可靠关系。

共享给 TEE 的内存也有相似的时间问题，不过关注点会变成：检查和使用是不是同一份内容、检查之后谁还能修改它。[TEE 的整数示例](/posts/tee-call-security/)先用值参数读清接口，再讨论换成缓冲区后多出的条件。

这样看，一块“安全内存”不是孤立的地址范围。它有访问主体，也有有效时间。把这两项省掉，权限图就只剩一张好看的地图。
