# 首页芯片滚动

记录首页要做的事。对话里的待办清单会随会话消失，以这份文档为准。

目标：首页钉住大约一屏半，一颗分层芯片跟着滚动分开。滚动只翻这一段。结束后仍是现有文章列表。文章页保持静止。

成片质感来自 Blender 渲染的序列帧，不是网页里实时算的三维。中文标题放在页面上，不刻进模型。

## 现在还做不了的原因

这个对话的 MCP 只有 IDA 和 JADX。`~/.cursor/mcp.json` 里没有 Blender。这台机器上也还没找到 Blender 应用。MCP 连的是本机已经打开的 Blender，渲染仍在本机计算。

## 按这个顺序做

1. 安装并打开 Blender，启用 **MCP for Blender** 插件，确认它正在监听。
2. 在 Cursor 的 `mcp.json` 里接入 `uvx mcp-for-blender`，让对话能连上本机 Blender。`uvx` 在 `/Library/Frameworks/Python.framework/Versions/3.12/bin/uvx`。
3. 用 MCP 搭 5 层无文字芯片，自下而上命名 `layer-01` 到 `layer-05`。
4. 用 Eevee 渲 96 帧 PNG。
5. 压缩序列帧，接到首页。滚动只翻这一段，下面仍是现有文章列表。
6. 五层做成可点的文字链接，对应现有系列。
7. 减少动效时直接显示已经分开的层和链接。离开首页时停掉滚动引擎。

## 场景

- 背景 `#0a0c0f`，贴近站点底色。
- 每层大约 `2 × 2 × 0.08`，略倒角，深灰金属，粗糙度约 `0.35`。
- 相机 `80mm`，放在斜上方。定好后不再旋转。第 1 帧到第 72 帧只轻微推近。
- 不要中文贴图，不用 Lux3D 生成整颗芯片。
- 帧率 `24`。分辨率 `1440×900`。PNG，8 位。
- 第 1 帧叠拢，第 72 帧沿厚度方向分开，第 96 帧停住。关键帧开头和结尾慢。
- 文件名从 `chip_0001.png` 连续编号。第 1 帧作封面，第 96 帧作定格。
- Eevee 先看分层和节奏。效果太平时，用 Cycles 重渲同一条镜头，换上同一段滚动。

## 网页

- 五层链接先对应现有系列：抓包实战、逆向基础、密码学基础、腾讯游戏安全 2026。多出的一层先不指向空文章。
- 启动链、Secure World、EL1、KeyMint 有文章之后，再改对应层的链接。
- 减少动效时不加载序列帧，直接给出分层和链接。
- 文章页不放这段滚动。
- 这个站有页面切换。滚动引擎如果没有卸载接口，离开首页时要停掉，避免监听留着。

## 先不做

- 不把 Anime.js 和这段滚动叠在一起。滚动只交给序列帧。
- 不把自由旋转、点击拆零件和这段成片放在同一个镜头里。
- 不把整套品牌叙事页流程装进文章站。
